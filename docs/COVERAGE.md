# 音效覆盖清单 · v0.3.3

版本：`0.3.3-peer-pickup-20260924`。62 件物品 / 62 条拿起参考 / 62 个索引组。相同和相近的声音可命中多组，组数不等于独立声音种类。

这次替换采用对方完整参考目录，没有混入我们的旧音效或放下素材。旧目录有 17 件没有对应参考，因此当前 62 件不是旧 51 件的简单超集。此前 51 件的覆盖记录见历史发布说明和 [旧库复核](COVERAGE-REVIEW.md)。

v0.4.3 更正：原标「红外线理疗灯」「天线」的两条参考是琥珀天心类、定位组物品的放下／转移声，现关联整类物品；这两件改由所在同音类的拿起参考覆盖，格数与图片不变。见 [放下声更正](PUTDOWN-RELABEL-20260924.md)。

完整参考自身匹配可以通过，但不代表实战准确。现有短窗口下，宝石项链、卡莫纳之星和钻戒仍低于门限；本次保留原识别逻辑。实录漏识别与误报限制见 [换库对照](OURS-PEER-LIBRARY-VALIDATION-20260924.md)。
