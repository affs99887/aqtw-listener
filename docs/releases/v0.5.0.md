# v0.5.0 · 物品库扩充到 150 件（便携预览版）

## 更新内容

- 物品从 62 件扩充到 150 件，新增三类声音：电脑硬件类（PSU 电源、显卡、固态硬盘、CPU、机械硬盘）、奢华茶具类（奢华茶具、香水、阻断剂注射枪、信息素试剂盒）、火焰喷灯。
- 「听样本」按钮统一放在卡片右侧。
- 候选卡片改为等宽紧凑排列，浮窗随内容收窄，不再铺满整行。
- 物品图按原比例显示，统一带稀有度底色。
- 修正胶囊电视（2×3）、花瓶（2×2）的格数。

## 实测

26 场对局录像回放：比上一版多识别 33 次物品操作，原有识别没有减少。

## 使用

下载 `AqtwListener-v0.5.0-win-x64.zip`，解压后运行 `AqtwListener.exe`。更新时保留自己的 `local-data` 文件夹，替换其余文件。
