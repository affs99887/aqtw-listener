# 行商助手 v0.6.0 · 展示物品与一键更新

## 更新内容

- 新增“展示物品”页：按声音分类、格数和品质（红 → 金 → 紫 → 蓝）勾选浮窗里显示的物品，支持按稀有度一键切换、预设和搜索，默认全部显示。不显示的物品仍计入大红概率，浮窗会注明“另有 N 件未显示”。
- 设置、展示物品、个人音效库和录音改存在 `%LOCALAPPDATA%\AqtwListener`，所有下载的版本共用；首次运行会自动沿用旧版的 `local-data`。
- 新增更新器：启动时自动检查新版本，点“立即更新”即可下载、校验并替换程序，完成后自动重启，失败会恢复原版本。也可在“诊断”页手动检查。

## 使用

下载 `XingshangAssistant-v0.6.0-win-x64.zip`，完整解压后运行 `行商助手.exe`，无需安装 .NET。从旧版升级时先从托盘退出旧版；之后的版本可直接在助手里一键更新。
