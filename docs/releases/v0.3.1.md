# v0.3.1 · 只采集游戏进程声音（预览版）

## 修复

- 监听与学习采音改用 Windows WASAPI 进程回环，只包含前台 `UAGame` 及其子进程的播放声。Discord、QQ、UU 等独立语音软件即使与游戏共用播放设备，也不会进入识别录音。
- 游戏进程退出或更换 PID 后，采音停止或重新绑定；无法确认游戏 PID、系统不支持进程回环、或进程回环启动失败时停止识别，不再退回会混入其他软件声音的整设备回环。
- 「采音」页的播放设备现只用于回放录音与试听参考音效，游戏采音不依赖该选择。诊断明确记录采音进程 ID 与试听设备。

进程回环需要 Windows 10 build 20348 或更新版本。如果朋友语音由游戏进程自身播放（游戏内队伍语音），它仍属于游戏音频；本次修复针对独立语音软件。

## 下载与更新

下载 `AqtwListener-v0.3.1-win-x64.zip`，解压后运行 `AqtwListener.exe`。退出旧版后替换程序文件，保留自己的 `local-data` 文件夹。发布包不包含个人设置、录音或学习草稿。

## 验证范围

Release 配置下核心测试 27/27、应用测试 41/41、浮窗 UI 检查通过。实机 Windows 11 build 26200 的进程回环探测：目标 `UAGame` 时，1 秒内收到 99 个音频包和非静音声音；目标改为当前无播放声的助手进程时，包的 RMS 为 0，游戏声音未进入该进程流。探测未保存原始音频，未直接测试 Discord／QQ／UU 的各版本。识别准确率、游戏内语音与远程链路仍需实机复测。
