# v0.2.0 · 顶部浮窗、声音对比与个人音效库（预览版）

## 本版内容

- 固定识别 UAGame，增加系统声音自动扫描，支持 UU 远程环境没有鼠标事件时触发识别。
- 识别中保留上次匹配，新增加载反馈和最近 100 条成功历史。
- 浮窗默认位于游戏客户区顶部居中，可进入操作模式锁定、解锁、移动和恢复位置。
- Ctrl+Alt+C 进入声音对比：回放片段、参考试听、相近音效、保存 WAV；操作期间暂停识别，退出清空采音缓冲并等待 300ms。
- 新增个人音效库、已有物品补样本、WAV 导入裁剪、新物品录入、先选物品的引导学习，以及导入导出与撤销更新。
- 更新主窗口分区、控件样式和托盘图标；基础库包含 9 个音效组、14 段参考和 51 件候选。

## 本次发布范围

这是回退至 2026-09-22 15:19 消息前功能状态的版本，并保留独立 GUI / 图标任务已接入的改进。本版仍使用候选分页，试听在操作模式中，字号在主窗口的浮窗设置中。取消分页、常驻试听和字号入口、横向扩展及图钉亮暗切换仍是后续需求，不作为本版已完成内容。

`docs/design` 是后续设计参考，生成图不代表已经实现的界面。软件以本次便携附件的实际行为为准。

## 下载与运行

下载 `AqtwListener-v0.2.0-win-x64.zip`，解压后运行 `AqtwListener.exe`。Windows x64 自包含便携版，无需另装 .NET 或 Go。更新已有版本时保留自己的 `local-data`；首次解压的发行附件不包含任何个人设置、录音或学习草稿。

本地开发目录的 `portable` 仍只维护一份最新未压缩程序，ZIP 仅用作本次 GitHub Release 附件。

## 验证与限制

核心、控制器、布局及个人库集成测试通过；参考音频回归与界面启动检查记录见 `docs/measurements/release-v0.2.0-*`。

这是预览版：参考及合成录音测试不代表实战准确率。真实游戏音效、UU 快捷键、多屏及 DPI 拖动、实际输出设备试听、独占全屏覆盖仍需实机验证。大金候选占比不是出货概率。
