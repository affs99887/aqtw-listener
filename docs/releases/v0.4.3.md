# v0.4.3 · 放下声更正、逐件差异率与原声试听（便携预览版）

修复拖动或转移胶囊电视时反复报「红外线理疗灯」的问题，并让「听样本」只播放未经处理的游戏录音。调查过程与数据见[放下声更正](../PUTDOWN-RELABEL-20260924.md)。

## 识别

- 库中标为「红外线理疗灯」「天线」拿起的两条参考，经 SoundRadar 原始录音核实分别是琥珀天心类、定位组物品放下或快速转移时的声音（相似度 0.996、0.968）。现改为关联整类物品（13 件、9 件），红外线理疗灯、天线按同音类并入对应拿起组。拖动放下或快速转移这些物品时，给出与拿起相同的候选。
- 拿起对应按住鼠标、放下对应松开鼠标：松开鼠标后出现的声音按放下声只记入历史（标「放下声」），不替换浮窗；按下后出现的声音按拿起声处理，不再被当成放下声扣留。收不到鼠标信号（如部分远程串流）时沿用原来的 1 秒时序规则。
- 放下声与拿起声给出同样的物品时，不替换拿起结果的逐件分数。
- 琥珀天心类 4 格大红概率因此由 5/5 变为 5/6，定位组 4 格由 1/3 变为 1/4。

## 界面

- 「匹配度」改为「差异率」，每张候选卡片显示自己的数值：差异率 = 100% − 相似度，保留一位小数，越低越接近。汇总行不再显示统一的匹配度；识别历史显示最低差异率。
- 「听样本」只播放 17 段 SoundRadar 原始游戏录音（逐字节保留，按时间窗口播放），覆盖 50 件物品，含琥珀天心类与定位组的放下录音。先播放本次匹配到的那种声音，右键可选该物品的其他录音。个人库物品播放学习时的原始录音。暂无原声的 12 件物品按钮置灰并说明原因。

## 验证

- 核心测试 41/41；应用与个人库测试 52/52；便携程序 `--ui-smoke` 布局检查全部通过。应用测试与 UI 检查在 Wine 9.0 中运行，尚未在 Windows 本机与游戏内复测。

## 使用与更新

下载 `AqtwListener-v0.4.3-win-x64.zip`，解压后运行 `AqtwListener.exe`，无需安装 .NET。更新时先退出程序，保留自己的 `local-data`，整体替换其余程序文件和 `library` 文件夹（新增 `playback` 文件夹与 `playback.json`）。旧的个人库版本仍可使用，试听会改用基础库原声；重新建库后也能试听自己录的原始片段。
