# v0.3.0 · 统一监听浮窗与按格数展示候选（预览版）

## 本版变化

- Ctrl+Alt+L 的持续监听结果与回放、保存 WAV、参考试听使用同一浮窗；回放或试听期间暂停采音，返回监听后继续识别。
- 候选按格数分区，每个格数组独占整行，不分页、不使用滚轮。每行 1／2 件为横向信息卡与固定宽度试听按钮，3／4 件为紧凑等宽卡，更多候选均衡分行；物品名称、匹配度和至少 80 DIP 的缩略图保持可见。
- 顶部移除跨格数的总百分比和进度条。各格数组显示“大红概率”及件数，计算方式为该格去重后大红候选数除以该格全部候选数；这不是游戏真实出货概率。
- 移除高分共享音效候选的多余标签和“展开相近音效”开关；小／中／大字号、单图钉固定／解锁状态直接在浮窗操作。
- 识别中显示加载状态，失败时明确提示且不清除已接受的有效结果。连续监听、历史记录与用户提供的新图标已接入。
- 核查社区音效来源后，基础库保留 51 件有音效依据的候选、9 个启用音效组和 14 段参考；未经确认的额外物品不预录入。

## 下载与更新

下载 `AqtwListener-v0.3.0-win-x64.zip`，解压后运行 `AqtwListener.exe`。这是 Windows x64 自包含便携包，无需另装 .NET 或 Go。附件不含个人设置、录音或学习草稿；从旧版更新时，退出程序后保留自己的 `local-data` 文件夹，再替换其余程序文件。

本地开发目录仍只维护一份未压缩的 `portable`。GitHub Release 的 ZIP 是单独的发布附件。

## 验证与限制

Release 配置的 27 项核心测试、39 项应用与布局测试通过，UI 检查通过。布局检查覆盖 1／6／13／15／51 件候选、每行 1–4 件、小／中／大字号、无分页与无滚轮；报告见 `docs/measurements/release-v0.3.0-core-tests.json`、`release-v0.3.0-app-tests.json` 和 `release-v0.3.0-ui-smoke.json`。截图为模拟候选，不代表实战识别结果。

本版仍是预览版。社区参考及其派生录音只能验证接入与回归，不能证明实战准确率；真实游戏音效、UU 远程、多屏 DPI、播放设备和独占全屏覆盖仍需实机验证。来源及许可边界见 [第三方说明](../THIRD-PARTY.md) 和 [音效来源核查](../SOUND-SOURCE-AUDIT.md)。
