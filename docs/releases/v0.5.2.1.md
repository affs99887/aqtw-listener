# 拾点 v0.5.2.1 · 软件更名

## 更新内容

- 软件正式更名为“拾点”，统一主窗口、侧栏、托盘、监听浮窗和启动提示中的名称。
- 启动文件改为 `拾点.exe`；Windows 文件属性中的产品名称、文件说明同步为“拾点”，版本为 `0.5.2.1`。
- 延续 v0.5.2 的候选四列上限、两件最小宽度、名称左对齐及快捷键恢复。

## 使用

下载 `Shidian-v0.5.2.1-win-x64.zip`，解压后运行 `拾点.exe`。更新时保留原来的 `local-data` 文件夹，原有设置、录音和个人音效库可继续使用。

## 验证

已使用更名后的 `拾点.exe` 检查 Windows 产品名称、文件说明和版本，并完成桌面界面检查。结果见 [测试报告](../TEST-REPORT.md)。
