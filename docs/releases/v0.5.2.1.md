# 行商助手 v0.5.2.1 · 图标与窗口行为修复

## 更新内容

- 软件名称统一为“行商助手”，同步主窗口、侧栏、托盘、监听浮窗、提示和 Windows 产品属性；启动文件为 `行商助手.exe`。
- 使用选定的透明 IND70 头盔图标，保留深色轮廓和镜片暗部。左侧图标放大为 72 逻辑像素，并按显示器缩放加载合适像素尺寸，改善小图轮廓清晰度。
- 右上角关闭、Alt+F4 和最小化均隐藏到系统托盘，保留监听状态；双击托盘图标或选择“打开设置”恢复，托盘菜单“退出”才彻底退出程序。
- 自定义浮窗允许移出屏幕四边，不再被定时定位拉回，靠近底边也不会自动压缩高度。可从托盘选择“恢复顶部居中”找回浮窗。
- 延续 v0.5.2 的候选四列上限、两件最小宽度、名称左对齐及快捷键恢复。

## 使用

下载 `XingshangAssistant-v0.5.2.1-win-x64.zip`，完整解压后运行 `行商助手.exe`，无需安装 .NET。

更新前先从旧软件的托盘菜单选择“退出”，再替换程序文件；保留原来的 `local-data` 文件夹，设置、录音和个人音效库可继续使用。旧启动文件 `拾点.exe`、`AqtwListener.exe` 请移出运行目录，避免误开旧程序。

## 验证

已检查 Windows 产品名称、文件说明、版本和图标资源，并完成应用回归及桌面界面检查，覆盖关闭到托盘、恢复与退出、四边越界位置保留、候选布局和图标显示。结果见 [测试报告](../TEST-REPORT.md)。

显示器缩放的后台渲染对比不等同于真实跨屏拖动实测；桌面检查不等同于游戏内独占全屏验证。
