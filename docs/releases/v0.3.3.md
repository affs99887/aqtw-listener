# v0.3.3 · 拿起素材库替换（便携预览版）

按用户选定方案，保留本项目自动触发、拿起短窗口、SoundRadar 特征匹配和多候选筛选，基础库替换为用户提供的 v0.67 工具中的 62 条拿起参考。目录门限 0.75、自动单次门限 0.78 保持不变，一声可以返回多个高匹配物品，不要求唯一答案。

- 移除放下辅助识别代码、确认状态和旧辅助素材。后续未匹配的声音仍保留之前已接受的候选及拿起录音。
- 62 件物品全部提供参考试听、缩略图和已补齐的格数。34 件保留原物品 ID 和图片；新增的机器人为 2×3、决胜奖杯为 1×2、骏骊逐浪图为 2×3，均由用户确认。
- 继续使用同一个监听浮窗、按格数展示大红概率和逐件匹配度、字号切换、回放、试听及个人建库。采音仍只绑定 UAGame 及其子进程。
- 导入的是素材和目录，没有采用另一款工具的识别代码或界面。来源与许可状态见 [第三方说明](../THIRD-PARTY.md)。

## 使用与更新

本地 `portable/AqtwListener.exe` 与 `AqtwListener-v0.3.3-win-x64.zip` 使用相同成品。ZIP 解压后直接运行，无需安装 .NET 或 Go。更新既有安装时先退出程序，保留自己的 `local-data`，完整替换程序及 `library` 文件夹；不要混用新旧目录和索引。`scripts/publish.ps1` 会清理输出目录中的旧基础库文件，保留 `local-data`。

个人库为独立版本；若其他安装此前已启用个人库，仍会按其原版本加载，需先在个人库中回退到基础库才能使用新的默认参考。当前用户的 portable 没有已启用的个人库，本次保留设置文件原样更新。
