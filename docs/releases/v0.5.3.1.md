# v0.5.3.1 · 国内下载与更新

## 更新内容

- 国内下载改走 Gitee：介绍页的下载按钮和助手里的一键更新，都优先从 Gitee 取安装包，国内可以直接下载。
- 一键更新先读取 Gitee 上带签名的版本信息，读不到再查 GitHub。安装包依次尝试 Gitee、介绍页、GitHub，某个地址 30 秒没有数据就换下一个；签名和 SHA256 都对得上才会安装。
- 安装包不再附带设计稿和截图，从约 123 MB 降到约 79 MB。程序功能不变。

## 使用

下载 `XingshangAssistant-v0.5.3.1-win-x64.zip`，完整解压后运行 `行商助手.exe`，无需安装 .NET。国内下载：https://gitee.com/scape0goat/aqtw-listener/releases 。从 v0.5.3 升级时，这一次建议手动下载安装；之后在国内也能一键更新。

## 旧版本升级补充（2026-10-27）

- **v0.5.3：**旧更新器只访问 GitHub；国内网络受限时需手动下载本版，安装后才具备 Gitee 更新能力。
- **v0.5.4（已撤下）：**其版本号比本版高，不会提示更新，手动检查也可能显示“已是最新版本”；请手动改用 v0.5.3.1。
- 先在“诊断”页确认版本和实际数据目录，再从托盘退出、完整备份个人资料，核对 ZIP 的 SHA-256 后解压到新文件夹。已存在的共享数据继续沿用，不要用旧 `local-data` 覆盖。

具体下载入口、PowerShell 校验命令、迁移条件与恢复步骤见 [旧版本手动升级指南](../UPGRADING.md)。本次只补充文档，不重发安装包、不改变更新安全机制。
