## 资源测量

环境：本机 Windows 10 x64、Intel i7-13700。自包含 Release 包，主窗口静态演示、监听关闭，测量约 5 秒。该状态不代表游戏内实时监听负载。

- 两进程合计 CPU：0.62% 的一个逻辑核心。
- 初始硬件渲染：两进程合计工作集 253.2 MiB，Private Bytes 238.3 MiB。
- 采用默认软件渲染后：合计工作集 166.7 MiB，其中 WPF 160.2 MiB、引擎 6.5 MiB；Private Bytes 137.1 MiB，托管堆约 9.4 MiB，CPU 仍约 0.62% 的一个逻辑核心。
- 同场景工作集下降约 34%。工作集包含共享页面；Private Bytes 是私有提交量，不能等同私有驻留内存。这是本机 5 秒静态观察，未代表长时间实战或所有显卡。
- WPF 的资源成本明显大于单独的识别核心；没有证据可以把整个软件称为已达到“卓越性能”。当前优势是按需识别、常驻引擎和事件驱动绘制，仍需游戏内 CPU/GPU/内存和低配机测量。
