## 识别浮窗

第 07 张 v2 为试听后的展开状态，恢复原版的格数分组与醒目的百分比。候选按占用格数升序分组，组头显示“2 格 / 4 格 / 6 格”等及组内数量；卡片继续显示宽×高尺寸。顶部以大号数字显示“大金候选占比”，并配大金数量/全部候选数量。示例为 50%（3/6 件），分母始终使用全部去重候选，相近音效不计入；空结果显示“—”。图中物品组合只用于多格数布局演示，不代表实际同音结果。

顶部直接回放、停止、保存当前声音，并提供返回监听和小/中/大字号入口；横向候选卡片各有“听样本”按钮。固定/解锁使用同一个图钉的亮/暗状态。v2 提示词与示例数据见 [overlay-v2-prompt.json](overlay-v2-prompt.json)，上一稿仍留存于原文件供对照。后续涉及候选展示的页面也必须继承格数分组和整体占比，不得因为视觉改造而省略。

优先横向利用游戏中间可用空间，窗口尺寸根据内容自适应，不照抄设计图像素尺寸。不分页，尽量减少滚动与向下遮挡。正常监听状态应更紧凑；极端数量、字号、分辨率组合仍需实机验证。

## 视觉规范

近黑背景 #101214、炭灰面板 #1A1E20、控件 #252B2F、细灰边框 #3B4245、偏白正文 #E4E8E5、次要文字 #969E9C，少量灰绿 #A8BDB1 表示状态。使用直角或极小圆角。红色与金色仅用于目录支持的物品信息。控件需要清晰悬停、按下、禁用与键盘焦点状态。

## 开发约束与生成偏差

业务以现有功能和已确认需求为准。参照 [15:19 后需求清单](../handoff/REQUIREMENTS-20260922-1519.md)，该清单仍标注待实施。

- 插图全部是生成示意，实施时用项目真实游戏缩略图。名称、格数、等级和数量由目录提供。第 09、10 张部分格数、等级有误；不能引入不存在的“传说/史诗”等标签。
- 候选占比不等于出货概率。第 23 张错误的“非出货概率：25%”文案必须删除，统一为“仅为候选占比，不代表出货概率”。
- 一个窗口仅用一个固定/解锁图钉；第 10 张卡片额外图钉不实现。
- “补库 / 学习”为合并入口，工作区保留四个标签；第 13、16 张分拆标签不作为要求。
- 图片选择只在本地发生；第 14 张“上传图片”改成“选择本地图片”。
- 装饰波形、额外游戏场景和操作按钮不代表新增功能；第 22 张采音提示实际应保持紧凑。
- 示例时间、数值、状态不代表实测数据；实际软件绑定真实状态。
