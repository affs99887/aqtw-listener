## 识别浮窗

第 07 张 v2 为监听浮窗在识别到声音后的展开状态，是历史结构示意；图中的顶部总百分比、并排分组与用词已被后续需求覆盖。当前实现把每个格数组独立放满一整行，标题直接写“2 格 / 4 格 / 6 格”等。组内显示“大红概率”：该格去重后的大红候选数除以该格全部候选数。顶部只显示候选数和最高音效匹配度，不显示跨格数的总比例。图中物品组合只用于布局演示，不代表实际同音结果。

顶部直接回放、停止、保存当前声音，并提供返回监听和小/中/大字号入口；横向候选卡片各有“听样本”按钮。固定/解锁使用同一个图钉的亮/暗状态。v2 提示词与示例数据见 [overlay-v2-prompt.json](overlay-v2-prompt.json)，仅作为历史设计参考。后续涉及候选展示的页面应遵循当前按格数整行分组和组内“大红概率”的要求。

实时监听和回放／试听共用这一种浮窗样式：标题栏、候选概览、操作栏、分组候选卡片和底栏始终存在。点击回放或试听后暂停采音，返回监听后继续自动识别。7–20 件候选优先向下排布，每个格数组占独立整行，物品名称和音效组匹配度醒目且完整显示；共享音效的高分物品不显示额外标签。极端更多候选才按需加宽。全部候选在同一页展示，不分页、不用滚轮，缩略图不低于 80 逻辑像素。底栏不设「展开相近音效」开关。实机遮挡与识别准确率仍需在游戏中验证。

## 视觉规范

采用深灰背景 #101116、面板 #1A1B21、控件 #252831 与细灰边框 #3B3D46，正文 #E9EAF0、次要文字 #A3A8B1。红色与金色用于目录支持的物品信息和分组比例。使用直角或极小圆角，控件保留悬停、按下、禁用与键盘焦点状态。用户提供的另一款工具仅用于功能和色调参考，沿用本项目的格数组和候选卡片结构，不复制对方的列表布局、视觉细节或文案。

## 开发约束与生成偏差

业务以现有功能和已确认需求为准。[15:19 后需求清单](../handoff/REQUIREMENTS-20260922-1519.md)保留当时的回退背景；当前实现与验证状态以[当前接续状态](../handoff/CURRENT.md)为准。

- 插图全部是生成示意，实施时用项目真实游戏缩略图。名称、格数、等级和数量由目录提供。第 09、10 张部分格数、等级有误；不能引入不存在的“传说/史诗”等标签。
- 界面按用户叫法标注“大红概率”，计算的是同格候选中的大红比例，不等于游戏实际出货概率；历史设计图中的错误概率文案不用于程序。
- 一个窗口仅用一个固定/解锁图钉；第 10 张卡片额外图钉不实现。
- “补库 / 学习”为合并入口，工作区保留四个标签；第 13、16 张分拆标签不作为要求。
- 图片选择只在本地发生；第 14 张“上传图片”改成“选择本地图片”。
- 装饰波形、额外游戏场景和操作按钮不代表新增功能；第 22 张采音提示实际应保持紧凑。
- 示例时间、数值、状态不代表实测数据；实际软件绑定真实状态。
