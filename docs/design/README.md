## 识别浮窗

第 07 张 v2 为历史结构示意；图中的顶部总百分比、并排分组与用词已被后续需求覆盖。当前按格数独立分区，标题直接写“2 格 / 4 格 / 6 格”等。组内显示“大红概率”：该格去重后的大红候选数除以该格全部候选数。顶部汇总候选数和识别时间，差异率逐件显示。图中物品组合只用于布局演示，不代表实际同音结果。

顶部提供回放、停止、保存、录音选择和暂停／返回监听，标题栏提供小/中/大字号入口；候选卡片右侧采用独立的 ▶ 试听小按钮，保留悬停说明和右键录音选择。固定/解锁使用同一个图钉的亮/暗状态。v2 提示词与示例数据见 [overlay-v2-prompt.json](overlay-v2-prompt.json)，仅作为历史设计参考。

实时监听和回放／试听共用标题栏、汇总与操作行、分组候选卡片，无底栏。点击回放或试听后暂停采音，返回监听后继续自动识别。2026-10-14 按用户反馈改为每行最多 4 件，并平衡宽高比例：中字号下，6 件用 2 列、13 件用 3 列、31 件用 4 列；不再一味选择最少列数。最小宽度为格数栏加两张候选卡片，排满行按整列收边；名称统一左对齐。超过六字的名称可完整两行，字号保持原值；缩略图按 1–6 / 7–20 / 21–48 件分别使用 88 / 80 / 56 逻辑像素。当前实际音效类在检查的空间内可同页展示，超大集合或极小空间可在操作模式滚动查看。后台渲染截图：[13 件](../screenshots/two-card-left-thirteen-20261014.png)、[31 件](../screenshots/two-card-left-thirty-one-20261014.png)，候选面板分别为 740×552 和约 824×732（不含标题栏）。本轮按用户要求不再启动界面测试窗口，尚未做新版完整窗口或游戏内验证。

## 视觉规范

采用深灰背景 #101116、面板 #1A1B21、控件 #252831 与细灰边框 #3B3D46，正文 #E9EAF0、次要文字 #A3A8B1。红色与金色用于目录支持的物品信息和分组比例。使用直角或极小圆角，控件保留悬停、按下、禁用与键盘焦点状态。用户提供的另一款工具仅用于功能和色调参考，沿用本项目的格数组和候选卡片结构，不复制对方的列表布局、视觉细节或文案。

## 开发约束与生成偏差

业务以现有功能和已确认需求为准。[15:19 后需求清单](../handoff/REQUIREMENTS-20260922-1519.md)保留当时的回退背景；当前实现与验证状态以[当前接续状态](../handoff/CURRENT.md)为准。

- 插图全部是生成示意，实施时用项目真实游戏缩略图。名称、格数、等级和数量由目录提供。第 09、10 张部分格数、等级有误；不能引入不存在的“传说/史诗”等标签。
- 界面按用户叫法标注“大红概率”，计算的是同格候选中的大红比例，不等于游戏实际出货概率；历史设计图中的错误概率文案不用于程序。
- 一个窗口仅用一个固定/解锁图钉；第 10 张卡片额外图钉不实现。
- “补库 / 学习”为合并入口，工作区保留四个标签；第 13、16 张分拆标签不作为要求。
- 图片选择只在本地发生；第 14 张“上传图片”改成“选择本地图片”。
- 装饰波形、额外游戏场景和操作按钮不代表新增功能；第 22 张采音提示实际应保持紧凑。
- 示例时间、数值、状态不代表实测数据；实际软件绑定真实状态。

## 图标与版本

2026-10-15 当前产品名称为 **行商助手**，图标采用用户选定的 D 版 IND70 头盔透明成品，保持源 PNG 不变。主窗口侧栏图标为 72×72 逻辑像素；主窗口标题栏与浮窗保留各自尺寸。[当前图标、九档尺寸与实际软件预览](brand/ind70-2026-10-15/index.html)。PNG 资源与 `Assets/listener-source.png` 逐字节一致；`scripts/export-icon.ps1` 调用栅格导出脚本，仅等比重采样为 16 / 20 / 24 / 32 / 40 / 48 / 64 / 128 / 256 px ICO，不再从旧矢量重绘。

清晰度修正：窗口标题栏、侧栏与浮窗的标志按逻辑尺寸乘显示器缩放后的物理像素解码，并随 DPI 变化重新选择缓存，余下缩放使用高质量模式。1254×1254 原图和透明留边不变，未锐化或改画图案。本地候选预览页默认比例为 100%，仍提供 75% / 60% 缩略查看。

以下为 2026-10-14 的历史「拾点」标志，不再是当前图标。[历史尺寸预览](brand/shidian-2026-10-14/index.html)。

选定概念由 GPT Image 生成，见[原始概念](brand/logo-minimal-2026-10-14/04-finding-point.png)与[提示词](brand/logo-minimal-2026-10-14/prompts.json)。应用资源按该轮廓整理为 `src/Listener.App/Assets/listener-mark.svg` 和 `listener-app.svg`；`scripts/export-icon.ps1` 从矢量源逐尺寸生成 PNG 与 16–256 px ICO。`scripts/draw-logo.py` 保留为导出命令的兼容入口。

原[灰白 / 灰绿图标概念](brand/listener-mark-concept.png)与 `listener-mark-preview.png` 中的物品格声波标志仅作历史设计参考。

旧 `gui-concept.png` 为早期方向，不属于本轮最终设计；开发以 `screens/` 和本说明为准。生成设计图本身不代表程序已更新，portable 的实现与验证情况见[当前接续状态](../handoff/CURRENT.md)。
