# 顶部浮窗、声音对比与个人音效库

## 使用

主窗口按监听、采音、位置、浮窗、音效库、诊断分区，无浮窗预览。

- **Ctrl+Alt+L**：监听开关；固定使用 UAGame。默认声音扫描不依赖鼠标，兼容 UU 无鼠标事件的场景。
- **Ctrl+Alt+C**：在同一监听浮窗进入或退出操作视图。自动识别后继续监听、保留结果；进入操作视图才暂停采音并可回放或逐件试听。监听时鼠标穿透。切到其他应用自动退出操作视图，本助手的文件对话框除外。
- 标题栏提供小／中／大字号，立即调整文字尺寸。
- 同一枚图钉切换固定和解锁：固定时亮起，解锁时灰暗。图钉灰暗仍可点击；解锁后拖动标题空白处，松手保存。拖动中 Esc 取消移动，其他时候 Esc 返回监听。
- 标题右键菜单「恢复顶部居中」恢复默认位置并固定；主窗口位置页和托盘也提供移动、恢复入口。

默认按游戏客户区顶部居中，上边距约 16 逻辑像素。监听时浮窗穿透并保留最新结果；按 Ctrl+Alt+C 打开操作视图后，浮窗显示标题栏、汇总与操作合并的一行，以及按格数分组的候选卡片，没有底栏。7–20 件结果中每个格数组独占整行，操作视图宽度约 830–910 逻辑像素，优先向下排布；极端更多候选才按需加宽，最大为游戏画面的 94% 或 1600 逻辑像素。全部候选一页显示，既不分页，也不使用滚轮；操作视图缩略图最低 80 逻辑像素。顶部锚点不动；自定义位置按显示器与相对位置保存。重启恢复位置和固定状态。

字号为 90%／100%／115%。监听结果的少量候选优先使用 112 逻辑像素缩图，多候选优先使用 96，空间不足时最低 80；调整不会覆盖保存的图片偏好。其他候选视图的图片默认 88、可独立调节 60–120。字号不会整体缩放候选图片。极小区域显示摘要与历史入口。录入保留工作视图和分步表单；历史记录以连续列表显示最近 100 条。

## 声音对比与识别反馈

鼠标触发立即显示「识别中…」，自动分析超过 150 毫秒再显示加载动画；快速完成直接更新状态。初步、最终、未匹配、无声音及错误分别显示；失败保留候选并标明为上次匹配。取消、切出、结束均关闭加载，旧分析不能覆盖新状态。

监听浮窗的汇总行显示候选数和识别时间，右侧是回放、停止（仅播放时可用）、保存 WAV、本次会话的录音选择和暂停／返回监听；完整候选直接按格数显示在同一界面。标题只写“2 格”等，每组以最大的数字显示该格的“大红概率”并按比例着色，旁边注明大红件数；顶部不显示跨格总概率或进度条。每张卡片突出完整名称，并在格数旁显示自己的差异率（100% − 与该物品参考音效的相似度，一位小数，越低越接近；共用同一条参考的物品数值相同），它不是单件确定率，也不额外显示同音标签。「听样本」只播放未经处理的原始游戏录音，先播放本次匹配到的那种声音，右键可选该物品的其他录音；识别用参考经过归一化和裁剪，不用于试听。实时结果超过 10 秒未更新时候选变暗并显示距今秒数。相近参考仅用于试听，不计入正式候选的大红概率。没有原声的物品按钮禁用并显示原因。大红概率是同格候选比例，不代表游戏真实出货概率，说明见汇总行的 ⓘ 提示。

声音、时间、正式结果、全库评分与音效库版本绑定，一次引擎分析同时返回评分和结果。历史显示原版本候选，声音过期后文字保留。最近 20 个有效片段、最多 100 条成功历史关联声音受 32 MiB 缓存上限约束；优先淘汰最旧且未选中的音频。选中的片段受保护。同一声音只播放一路，使用已选播放设备。退出操作会停止播放、清空采音缓冲，完整等待 300 毫秒后按监听开关与游戏前台状态恢复。

普通片段和本次历史仅在内存，退出软件清空。只有点击保存 WAV 才把普通片段写入文件。「识别历史」提供「在浮窗中对比」，松开鼠标后的声音标为「放下声」，收不到鼠标信号时把拿起后 1 秒内的其他音效标为「疑似放下声」，两者都不替换浮窗。

## 补库与新物品

在浮窗「补库 / 学习」先选择实际物品，可使用当前片段或导入 WAV，试听、裁剪、删除样本。单次入库片段为 0.19–5 秒；支持保留原始录音并重新裁剪；启用后「听样本」播放这段原始录音，而不是重采样后的识别副本。新物品分两步填写名称、大红/非大红、宽×高格数，图片与参考价可留空。

新物品默认独立组，阈值 0.82；原组阈值保留。用已停用引擎建成的旧个人库版本会自动改用基础库并提示重新建库。和已有组相近时先显示冲突供试听，用户确认同音关联后才继续。无需修改基础 library。个人库可管理物品与样本、启停、删除、继续草稿、重新采样、导入导出 `.aqtwlib`、撤销最近一次更新。禁用最后一段参考前需禁用该新物品，避免启用无参考的音效组。

## 引导学习

1. 选定真实物品，点击「引导采样」明确开始保存本轮录音。
2. 自动暂停普通识别，浮窗穿透，等待游戏处于前台。每轮 3 秒准备，然后提示拿起并保持。
3. 采音 1.2 秒，结束后再放下。三轮参考加一轮单独试识别；静音、过短、削波、重复原录音或重叠窗口拒绝并补录。
4. 切出游戏暂停、切回重新倒计时；Ctrl+Alt+C 暂停并操作，草稿保留，可继续或重采样。需要移动浮窗先暂停。
5. 第四轮不参与本次建库。构建、参考回归、试识别通过且同音关系确认后自动启用；失败保留草稿与原因、继续原库。普通匹配结果不会自行变成标签，也不会自动降低阈值。

本轮留出试识别与原库参考回归是工程检查，不能证明独立实战准确率。真实的双颈琴等库外物品需本人选择、录制、验证，不能从已有相似候选推断标签。

## 数据与恢复

- 基础库：`library`，包含校验后的 14 段参考片段、图片、目录和声纹索引。
- 个人资料：`local-data/personal`。原录音、裁剪片段、草稿、图片、完整版本跨重启保存，发布包排除整个 `local-data`。
- 样本记录来源、录制编号、会话、裁剪时间、哈希、参考/试识别用途和可用的采音窗口时间。裁剪保持原录音身份，重叠窗口不算独立录音。
- 每次更新合成完整新版本，沿用现有 DSP，检查索引内容、哈希、参考回归及试识别，再整体切换；取消旧识别任务。失败不修改活动指针，损坏版本优先退回可用旧版本或基础库。
- 每个构建版本有 `build-report.json` 和 `reference-checks.json`。引擎未生成声纹的样本会列出；现有引擎不返回详细跳过原因，报告明确说明声纹未生成及可能的音频质量问题。
- 删除、禁用是对当前个人库生效；为支持撤销，旧版本及关联文件仍保留。升级程序请保留自己的 `local-data`。

## 验证范围

分阶段记录见 [测试报告](TEST-REPORT.md)。自动化覆盖零鼠标采样、状态切换、300 毫秒恢复等待、缓存、重叠录音、真实引擎重建、同音确认、试识别失败、导入导出与回退；界面检查用独立实例，无全局快捷键或输入钩子。

真实游戏里的多屏热插拔、跨不同 DPI 拖动、Esc 取消原生拖动、UU 快捷键与音频转发、游戏所选播放设备、双颈琴/琥珀物品录音及独占全屏覆盖仍需实机验证。数学布局覆盖窗口化、负坐标及多种 DPI，不等同于这些硬件场景均已实测。
