旧版本手动升级指南

核查日期：2026-10-27。当前正式版为 v0.5.3.1（2026-10-16 发布）；v0.5.4 已撤下，其下载与包体积改进已并入 v0.5.3.1。以下文件名与校验值仅适用于 v0.5.3.1；以后发布新版时，请使用对应发行版的安装包和校验值。

1. 先确认正在运行的版本

打开助手主窗口 → 诊断 → 版本与更新，查看“当前版本”，同时记下下方的“数据目录”。以这里显示的版本为准，不以解压文件夹名判断。

当前版本 应该怎么做
v0.5.3（或 v0.5.3.0） 旧更新器只访问 GitHub，不能通过新加入的 Gitee 更新信息升级。在国内检查超时或下载失败时，按本文手动升级一次；GitHub 能正常访问时仍可使用旧更新器。
v0.5.4（或 v0.5.4.0，已撤下） 手动改用正式版 v0.5.3.1。版本比较认为 0.5.4 大于 0.5.3.1，因此不会提示更新，手动“检查更新”也可能显示“已是最新版本”。这不表示 v0.5.4 仍在正式发布。
v0.5.3.1 已是本次核查的正式版，无需重装；以后可在“诊断”页检查更新。
其他版本 先核对官方发行页。不要仅根据本文给将来发布的新版本降级；更早版本也应先备份再手动换包。

升级完成后才能使用新版的国内更新能力；只更新网站或 Gitee 上的文件，不会改变已安装的旧更新器。不要修改本地版本号来强行触发更新。

2. 退出并备份个人资料

  1. 先记下“诊断”页的实际数据目录，然后在系统托盘右键助手图标 → 退出。关闭主窗口只是隐藏到托盘；确认助手进程已经结束，也没有正在进行的更新。
  2. 将整个数据目录复制到程序目录之外、带日期的备份文件夹，例如 文档\行商助手备份-20261027\共享数据。默认路径为 %LOCALAPPDATA%\AqtwListener，可按 Win+R 粘贴打开；如设置过 AQTW_DATA_DIR，请备份诊断页显示的自定义路径。
  3. 旧程序旁如果还有 local-data，也完整复制到另一个备份子文件夹，例如 旧版-local-data，不要与共享数据混合。保留旧程序文件夹，确认新版资料正常后再清理。

备份应包括设置、展示物品配置、个人音效库、录音和学习草稿等全部内容。不要只备份 settings.json，也不要删除共享目录或 migrated.json 来“重置迁移”。v0.5.3 / v0.5.4 已使用共享目录时，旧 local-data 可能已经过时，不能覆盖较新的共享资料。

3. 从官方入口下载

  • 国内下载：Gitee v0.5.3.1 发行页
  • Gitee 直接下载 Windows 便携包
  • 备用：GitHub v0.5.3.1 发行页
  • GitHub 校验文件 SHA256SUMS.txt

下载的文件应为 XingshangAssistant-v0.5.3.1-win-x64.zip，大小 82,714,834 字节（约 78.88 MiB）。不要选择网站自动提供的 Source code / 源代码 ZIP，也不要使用已撤下的 v0.5.4 或第三方重新打包文件。

4. 先校验，再解压运行

在 Windows PowerShell 中运行下面的命令，把第一行改为下载文件的实际路径。代码只读取文件并检查，不会启动或安装程序。

$packagePath = 'C:\Users\你的用户名\Downloads\XingshangAssistant-v0.5.3.1-win-x64.zip'
$expectedHash = '9b988d3ae2656c41f98f0fc06a45e20e3134bbd563688b440d431698bdd6eaea'
$actualHash = (Get-FileHash -LiteralPath $packagePath -Algorithm SHA256 -ErrorAction Stop).Hash
if ($actualHash -ine $expectedHash) { throw 'SHA-256 不一致，请停止解压和运行，重新从官方入口下载。' }
if ((Get-Item -LiteralPath $packagePath -ErrorAction Stop).Length -ne 82714834) { throw '文件大小不一致，请重新下载。' }
'校验通过，可以完整解压。'

应得到的 SHA-256（不区分大小写）：

9b988d3ae2656c41f98f0fc06a45e20e3134bbd563688b440d431698bdd6eaea

这个值与 GitHub 正式发行附件摘要及签名更新清单中的安装包哈希一致。也可从 GitHub 正式发行页下载 SHA256SUMS.txt，核对同名 ZIP 对应的一行；不要把校验文件自身的哈希当成安装包哈希。若哈希不一致或无法核对，不要运行文件，也不要跳过检查。

手动下载时，上述 SHA-256 检查用于核对文件是否与官方发布一致，不等于执行了 ECDSA 验签。v0.5.3.1 的自动更新会验证 Gitee / GitHub Pages 更新清单的 ECDSA P-256 签名，并按清单中的 SHA-256 校验安装包；两份签名清单都不可用时，保留原有 GitHub Release 与 SHA256SUMS.txt 回退流程。本指南不要求关闭校验、修改清单或签名、更换公钥，也不修改更新器。

5. 完整解压到新文件夹，再确认数据条件

把校验通过的 ZIP 完整解压到一个新的空文件夹，例如 D:\Apps\行商助手-v0.5.3.1。不要在压缩包内直接运行，不要只替换 EXE / DLL，也不要把新旧程序及 library 混合覆盖；无需重新安装 .NET。

**已经有共享数据（v0.5.3 / v0.5.4 的通常情况）：**使用同一个 Windows 账户、同一 AQTW_DATA_DIR 设置启动新版，即可继续读取原数据目录。无需把备份复制到新程序文件夹，也不要用旧 local-data 覆盖共享数据。

**只有旧版 local-data、共享目录尚未初始化：**在第一次启动新版之前，把旧 local-data 整个文件夹复制到新 行商助手.exe 所在目录旁，保持名称 local-data。程序只检查自己旁边的这个目录，不会搜索其他旧安装位置。迁移是复制，不会移动或删除旧资料。

迁移条件是目标没有 migrated.json 且为空（代码允许仅有 display.json）；已有其他文件时不会再次导入，也不会合并覆盖现有文件。若共享目录已初始化而旧资料仍未导入，先停止操作，保留两边完整备份并通过反馈入口处理；不要为触发迁移删除当前目录或标记文件。

6. 启动并核对

运行新文件夹中的 行商助手.exe，在“诊断”页确认：

  • 当前版本为 v0.5.3.1，数据目录与此前记下的路径一致（首次从 local-data 迁移的情况除外）。
  • 快捷键、展示物品勾选、个人音效库、录音和学习草稿仍在；抽查自己熟悉的一项设置和一条个人样本。
  • 可以手动“检查更新”。当前没有更新是正常的；将来有更高正式版本时才会提示。“启动时自动检查更新”可按需开启。

最后更新桌面 / 任务栏快捷方式，确保它们指向新文件夹。旧程序和备份至少保留到确认资料与功能都正常之后；共享数据目录不随旧程序文件夹一起删除。

7. 异常时先保留数据

  • **仍显示 v0.5.3 或 v0.5.4：**通常是旧快捷方式或旧进程仍在运行。通过托盘退出，确认结束后，从新文件夹启动；不要反复覆盖程序。
  • **资料看起来丢失：**立即退出，先备份当前数据目录。核对 Windows 账户、“诊断”页路径和 AQTW_DATA_DIR；不要创建大量新资料或将新旧备份混合覆盖。需要恢复时，在助手退出后将当前目录重命名保留，再把升级前备份整个复制为原路径下的数据目录（不要与当前目录合并）；首次迁移用户仍保留旧 local-data 原件。
  • **校验失败或检查更新失败：**保留原数据和已验证的旧程序目录，重新从官方入口下载并校验。网络失败不应通过关闭签名 / 哈希检查解决。v0.5.4 不是推荐的回退版本。

仍无法处理时，在“诊断”页导出诊断，通过 问题反馈 提供版本、错误信息和目录情况；发布前检查诊断内容，勿公开完整个人数据备份。
